PEGASUS Local Images Directory
==============================

Place real, verified company photographs here to activate image displays:

1. hero.webp (Recommended 1920x1080, <300KB)
   - Real vehicle or Hurghada scenery photograph.

2. about.webp (Recommended 1200x800, <200KB)
   - Real chauffeur or representative photograph.

3. share.webp (Recommended 1200x630, <150KB)
   - Social media share preview card.

4. Tour & excursion photos:
   - Specific tour photos can be set when creating/editing tours in the Admin Dashboard.

When a file is uploaded, update HAS_REAL_IMAGES in src/config/images.ts to enable it.
If an image is missing, the site gracefully renders an elegant luxury brand background
without resorting to generic stock or Unsplash photos.
